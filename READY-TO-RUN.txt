METHOD 2: MANUAL START
────────────────────────────────────────
Open 3 separate terminals:

Terminal 1 - Backend:
cd backend
npm run start:dev

Terminal 2 - AI Service:
cd ai-service
..\.venv\Scripts\python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

Terminal 3 - Frontend:
cd frontend
npm run dev

Then open: http://localhost:3000

🛠️ TROUBLESHOOTING QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════
Issue: Services won't start
→ Close all terminals, run START-DEMO.bat again

Issue: Port already in use
→ Close other applications using ports 3000, 3001, 8000
→ Or run: netstat -ano | findstr :3000 (find and kill process)

Issue: Frontend shows "Cannot connect"
→ Verify backend is running (check terminal window)
→ Test: http://localhost:3001/api/v1/health

Issue: Questions not generating
→ Check AI Service terminal for errors
→ Verify internet connection (OpenAI API needs internet)
→ Check OPENAI_API_KEY in ai-service/.env

Issue: Database error
→ Verify internet connection (Neon is cloud database)
→ Check DATABASE_URL in backend/.env
